# 全站搜索

## 目标

读者在任何页面都能一次查遍日报、应用和 Skill（PRD R15「用户跨模块找到主题」，第一期「跨模块搜索」）。上线时：顶栏有搜索入口，一个搜索页按类型分开显示结果，每条都看得出是新闻、应用还是 Skill；只返回已发布的内容；没结果时保留输入，给下一步。

## 设计稿

- 「IFAI 首页」画板：顶栏右侧语言按钮左边的放大镜按钮（44×44）。
- 「空状态与加载状态」画板：「搜索无结果」（胶囊形搜索框保留输入、`role="status"` 的「没有找到「…」相关内容」、换短一点或英文的提示、一排热门词；结果行是 36px 图标 + 标题 + 一行灰字类型）和「页面不存在」（404 上的搜索框，占位文字「搜索日报、应用和 Skills」）。
- 画布上没有搜索结果页本身的画板，结果页按上面两处的元素拼：搜索框、类型标签（全部 / 日报 / 应用 / Skills，带数量）、结果行。「照实现补的画板」下还要补一张「全站搜索（照实现）」，另开一个 PR 做。

和画板不一致的地方：

- 画板的「你是不是要找：agent 代码审查」纠错建议这一期不做：要先有搜索日志或词表才知道该纠成什么，硬猜不如不给。
- 画板的「大家在搜」要有搜索记录才说得出口。这一期不记录搜索词，改成「热门」：热度最高的 4 个应用和安装最多的 2 个 Skill 的名字，点了就搜它。

## 数据

不建新表，直接读各模块已有的公开数据，权限和各模块列表页一样（`overrideAccess: false`，只有已发布的）：

| 类型 | 查哪些字段 | 排序 |
|---|---|---|
| 日报 `daily` | 已发布新闻的标题、摘要，五种语言都查 | 新的在前 |
| 应用 `apps` | 名称、别名、一句话介绍、标签，五种语言都查（和 `/apps?q=` 同一个条件） | 名称完全相同的在最前，名称以它开头的其次，其余按热度 |
| Skills `skills` | 显示名、一句话介绍、标签、slug，五种语言都查（和 `/resources?q=` 同一个条件） | 同上，其余按资源列表的「综合」 |

撤回的新闻、草稿和下架的应用、没有已发布版本的 Skill 都不出现。类型跟着 `NEXT_PUBLIC_SITE_PHASE` 走：模块没上线就不出现它的标签，以后推荐、圈子、Wiki 上线时各自加一种。

这一期用 Postgres 的 `ILIKE`（经 Payload 的 `like`）：第一期内容是几百条量级，够用。内容多到搜索变慢、或者要分词和容错时再接 Meilisearch（AGENTS.md「对应模块开工时再接入」）。

## 页面与路由

`/[locale]/search?q=…&type=…&page=…`

- `q`：去掉首尾空白、连续空白并成一个，最多 64 个字符。空的时候只显示搜索框和「热门」。
- `type`：`all`（默认，地址里不写）、`daily`、`apps`、`skills`；不认识的当 `all`。
- 「全部」：按导航顺序分三段（日报、应用、Skills），每段最多 5 条，段尾「查看全部 N 条」切到那个类型；没有结果的段不显示。
- 单个类型：每页 20 条，上一页 / 下一页。`page` 不是从 1 起的整数、或超过最后一页时返回 404。
- 结果行：图标（应用用 logo 或首字母方块，Skill 用首字母方块，新闻用日报图标）、标题、一句话介绍或摘要（一行）、灰字「类型 · 分类 / 作者 / 日期」。缺读者语言的内容回退英文并标 `lang`，和各模块列表页一样。
- 页面标题「搜索：q」，`noindex, follow`，不进站点地图。
- 顶栏：语言按钮左边加放大镜链接到 `/search`；在搜索页上它标为当前页。
- 404 页：标题下面加同样的搜索框。
- 不缓存搜索结果（每个词都是一份缓存）；热门词跟着应用和 Skill 的缓存走。

## 后台

无。

## 定时任务与 AI

无。不调用模型，不记录搜索词。

## 多语言

界面文案五种语言（`search` 命名空间），繁体由 `pnpm i18n:hant` 生成。读者用哪种语言搜都能命中任何语言的字段：用中文搜英文页面上的应用也能找到。

## 不做

- 纠错建议、搜索联想（边输边出结果）、搜索词记录和「大家在搜」。
- 全文搜索新闻正文和 Skill 文件内容；分词、同义词、拼音。
- 单独的搜索 API（`/api/search`）：页面直接读数据；以后 App 或助手要用再加。
- 按时间、分类筛选：要细筛就去各模块自己的列表页（应用、资源列表都有搜索）。

## 验收标准

- [ ] 五种语言的顶栏都有搜索按钮，键盘能聚焦，读屏读出「搜索」；手机宽度不挤掉语言和账号按钮。
- [ ] `/en/search` 空搜索显示搜索框和热门词；点一个热门词就搜它。
- [ ] 搜一个应用名：「全部」里应用段把它排第一，标题旁看得出是「应用」，点进去是它的详情页。
- [ ] 搜一个只在中文介绍里出现的词，英语页面也能搜到，结果标 `lang`。
- [ ] 草稿、下架的应用，撤回的新闻，没有已发布版本的 Skill 都搜不到。
- [ ] 类型标签的数量和切过去后的条数一致；单个类型翻页正常，`?page=0`、超出最后一页返回 404。
- [ ] 没结果：保留输入，`role="status"` 读出「没有找到」，给热门词。
- [ ] 404 页能直接搜。
- [ ] 搜索页 `noindex`，不在 `sitemap.xml` 里。
- [ ] 手机宽度（390）下搜索框、标签、结果行不横向滚动。
