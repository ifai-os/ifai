# 账号

## 目标

读者自己管理 IFAI 账号：从右上角的账号菜单进入自己的东西，用 Google、GitHub 或邮箱链接登录，在「设置」里改昵称、管登录方式和登录的设备、看邮件、换语言、下载数据和删除账号。

第一期上线前做完不依赖圈子的部分。依赖圈子数据的（个人主页、关注和屏蔽、站内通知、隐私设置、第一次登录后的「设置公开资料」和「加入圈子」）由圈子模块的规格负责，见文末「留给圈子」。

## 设计稿

画布上的四个画板：

| 画板 | 内容 | 这一期 |
|---|---|---|
| 「IFAI 账号菜单与通知」 | 头像菜单、通知面板、没登录时的入口 | 头像菜单（去掉圈子、评价、外观）；通知面板留给圈子 |
| 「IFAI 登录与完善资料」 | 登录、链接已发送、设置公开资料、加入圈子 | 登录和链接已发送；后两步留给圈子 |
| 「IFAI 个人主页」 | 别人看到的和自己看到的主页 | 整页留给圈子；「收藏」标签已经是「我的收藏」页 |
| 「IFAI 账号设置」 | 设置页六个分区 | 五个分区，「隐私」留给圈子 |

和画板不一样的地方：

- **昵称最多 30 个字**（画板写 20）：写应用评价时已经可以改名字，上限是 30（`reviewRules.maxName`），两处用同一个上限。
- **不做头像上传**：要先有图片上传和审核。头像一律是昵称的第一个字，颜色按账号 id 固定，和评价上的头像一样。Google、GitHub 带来的头像图片不显示。
- **不做「外观」**：站点还没有深色主题。菜单里的「外观」和设置里的「外观」一行等深色主题做好再加；「外观与语言」这一期叫「语言」。
- **登录邮箱不能自己改**：画板上的「更换」要给新邮箱发确认信，等 Resend 配好、有人需要再做。
- **登录的设备不写城市**：画板写「上海 · 现在」，这里没有按 IP 查位置的服务，写 IP 地址和登录时间。
- 页面底色是白色，画板里的白卡片改成浅边框的卡片。

## 数据

不加表，不用迁移。

- 昵称：`auth_users.name`。评价上显示它，以后圈子的动态和评论也显示它。
- 登录方式：`auth_accounts`（Google、GitHub 各一行）。邮箱链接登录不建行，登录邮箱是 `auth_users.email`。
- 登录的设备：`auth_sessions`。
- 日报邮件：按登录邮箱查 `subscribers`，只在邮箱验证过时查（和导出一样：只有读者证明过是自己的邮箱才算他的）。

## 页面与路由

### 账号菜单

右上角头像（昵称第一个字，颜色同上）。点开是一个 300px 宽的菜单：

- **最上面**：头像、昵称（没有昵称时写邮箱 @ 前面的部分）、登录邮箱，点了去「设置」。
- **我的收藏** → `/me/saves`；**我的关注** → `/me/following`（画板上没有，日报关注加的，见 [daily.md](./daily.md)「关注」）；**我的提交** → `/apps/submit#mine`（提交应用页的「我的提交」，没提交过时就是提交表单）。
- **最下面一排**：「账号设置」和「退出登录」，图标在上、字在下。
- Esc 和点菜单外面关掉菜单，Esc 后焦点回到头像。

不做：我的圈子、我的评价、各项后面的数字、外观、通知铃铛。

### 登录

`/[locale]/sign-in`，以及收藏、评价、投稿时弹出的登录对话框，用同一个表单。

- 邮箱表单下面加一行「不用设密码。第一次登录会自动创建账号。」（登录页有，对话框里没有，对话框空间小）。
- **链接已发送**：登录页上标题换成「登录链接已发送」，下面写「去 *邮箱* 查收，链接 10 分钟内有效。在这台设备上打开链接，就能直接登录。」，灰底提示「没收到？先看看垃圾邮件文件夹，公司邮箱有时会晚几分钟。」，按钮「换个邮箱」（回到表单，邮箱还在）。60 秒内写「56 秒后可以重新发送」，倒数到 0 变成「重新发送」按钮，按了再发一封、重新倒数。对话框和设置页里也是这些内容，只是标题不是页面标题。
- Better Auth 自己限制同一地址 60 秒内最多发 5 次登录链接，60 秒倒数不会碰到它。

### 设置

`/[locale]/me/account`，标题「设置」，账号菜单里叫「账号设置」。不进索引、不进 sitemap，每次请求现读。

- 没登录：说明一句，下面是登录表单，登录后回到原来的分区。删除账号之后：显示「账号已删除」（和现在一样）。
- 分区用地址区分：`?section=profile`（默认）、`sign-in`、`notifications`、`language`、`data`，不认识的当作 `profile`。桌面左边一列分区名（200px，跟着滚动），手机上分区名是一排可以横着滑的按钮，在标题下面。当前分区 `aria-current="page"`。

**个人资料**

- 头像（第一个字）和说明「头像是昵称的第一个字。」
- 昵称：输入框，右上角字数「8 / 30」，下面写「写应用评价时显示这个名字。」按「保存」，成功后旁边写「已保存」，头像和菜单跟着变。空的不能存（「请填写昵称」）。
- 服务器也检查：`/api/auth/update-user` 收到的昵称去掉看不见的字符、换行折成空格、截到 30 个字，剩下空的拒绝（`auth.ts` 的 `hooks.before`）。写评价时改名走的也是这里。

**账号与登录**

- 登录邮箱：只显示。
- 登录方式：配了哪种第三方登录就列哪种（Google、GitHub），再加一行「邮箱登录链接 · 一直可以用，不用设密码」「默认开启」（配了邮件才有这一行）。
  - 没连接的写「没有连接」，按钮「连接」：跳到 Google / GitHub 授权，回来后提示「已连接 Google，以后也可以用它登录。」第三方账号的邮箱可以和登录邮箱不一样（`allowDifferentEmails`）。这个第三方账号已经是另一个 IFAI 账号的登录方式时，提示「这个 Google 账号已经用来登录另一个 IFAI 账号，不能再连接到这里。」；其他失败写「没能连接，请稍后再试。」
  - 已连接的写「已连接 · 2026年10月3日」，按钮「断开」。断开要一天内登录过（和删除账号一样，Better Auth 的 `freshAge`），不然提示重新登录。只剩这一种登录方式、而且这个环境不能用邮箱链接登录时，不能断开（按钮不可用，写「这是你现在唯一的登录方式，不能断开。」）；能用邮箱链接时可以断开，以后用邮箱链接登录（`allowUnlinkingAll` 按邮件有没有配好开关）。
- 登录的设备：每次登录一行，当前这台在最前面、标「当前设备」，其他按登录时间新的在前。每行写设备（由浏览器标识认出「Mac · Chrome」「iPhone · Safari」，认不出写「未知设备」）、IP 地址和登录时间。其他设备有「退出」，下面有「退出其他所有设备」。退出后那台设备最多 5 分钟后变成没登录（登录状态在浏览器里缓存 5 分钟，`cookieCache`）。
  - 退出一台：`DELETE /api/account/sessions/<id>`，只给登录会员、只接受本站页面发来的请求，只能退出自己的、不能是当前这台（当前这台用「退出登录」）。会话令牌不给浏览器。
  - 退出其他所有设备：Better Auth 的 `revokeOtherSessions`。

**通知**

- 邮件：「账号与安全邮件 · 登录链接这类邮件」「不能关闭」。
- 日报邮件：
  - 登录邮箱订阅着：「每天早上 8 点（你所在的时区）发到这个邮箱。」链接「管理日报订阅」到管理订阅页（带这个订阅的令牌，可以改语言、时区、退订）。
  - 停发了（退信、被标成垃圾邮件、站长停发）：写「已经停发」，链接同上，管理订阅页上说明原因。
  - 没订阅或已退订：「每天早上 8 点的 AI 日报，单独订阅、单独退订。」下面是日报的订阅框（邮箱已经填好）；订阅没开放的环境不显示订阅框。
- 站内通知（有人关注、回应、评论）随圈子一起做。

**语言**

- 界面语言：五个按钮，各用自己的语言写（English、简体中文……），当前的按下。点了换到那种语言的同一个分区，记在 `IFAI_LOCALE` cookie 里，和顶栏的语言切换一样。
- 说明「日报邮件的语言在日报订阅里单独设置。」
- 不写进账号（`ui_locale` 仍然空着）：现在没有按账号发的、需要语言的邮件。

**数据与账号**

「下载我的数据」和「删除账号」，内容和行为见 [foundation.md](./foundation.md)「导出我的数据」「账号页与删除账号」，不变。重新登录后回到这个分区。

## 多语言

界面文案在 messages 的 `header`、`auth`、`account`，五种语言。设备名和浏览器名（Mac、Chrome）不翻译。

## 不做

- 头像上传、换登录邮箱、外观（深色）、我的评价页。
- 登录设备的城市、设备的「最近活动」时间。
- 第一期没有的模块的入口（圈子、推荐、排行、Wiki 的东西不出现在菜单和设置里）。

## 留给圈子

这些要用圈子的数据，由圈子模块的规格（`docs/specs/circles.md`，圈子线程负责）在之后的步骤里做；做的时候往设置页加分区（`src/components/account/sections.ts`），往删除账号和导出加表：

- 个人主页 `/u/<主页地址>`：主页地址、一句话介绍、个人网站，动态 / 文章 / 评价 / 圈子标签，关注和关注者。
- 关注、屏蔽、举报用户。
- 通知铃铛和通知面板，设置里的「站内通知」和「每周互动汇总」邮件。
- 「隐私」分区：主页显示加入的圈子、允许搜索引擎收录主页、谁可以评论我的动态、屏蔽的人。
- 「自动翻译其他语言的动态」。
- 第一次登录后的「设置你的公开资料」和「加入几个感兴趣的圈子」。
- 菜单里的「我的圈子」，删除账号时「你是圈主，先转给别人」的提示。

## 验收标准

- [ ] 账号菜单：头像、昵称和邮箱，我的收藏、我的关注、我的提交、账号设置、退出登录都能用；Esc 和点外面能关掉，Esc 后焦点回到头像
- [ ] 登录页发出链接后显示「登录链接已发送」、垃圾邮件提示和 60 秒倒数，倒数完能重新发送，「换个邮箱」回到表单
- [ ] 设置页五个分区能用地址直接打开，手机宽度下分区按钮能横着滑，没登录时登录后回到原来的分区
- [ ] 改昵称后评价上显示新名字；空昵称存不了，接口直接调也存不了
- [ ] 连接、断开 Google 和 GitHub（预览环境，配好两种第三方登录后）；超过一天没登录时断开会提示重新登录；只剩一种登录方式又不能用邮箱链接时不能断开
- [ ] 登录的设备列出每台设备，退出一台和退出其他所有设备后，那些会话从数据库里没了，当前这台还登录着
- [ ] 订阅了日报的会员在「通知」能进管理订阅页；没订阅的能直接订阅
- [ ] 在「语言」换语言后留在同一分区
- [ ] 五种语言、手机和桌面截图走查
