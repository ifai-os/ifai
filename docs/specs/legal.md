# 法律页面：隐私政策与用户协议

## 目标

站点已经在收集邮箱、登录记录、评价、投稿和日报订阅，上线前要有两页读者看得懂的说明：隐私政策写清楚收集了什么、为什么、交给了谁、留多久、怎么删；用户协议写清楚读者能做什么、不能做什么、站内内容和 Skill 的边界。

条文是按现有功能起草的稿子，**正式上线前请懂当地法律的人看一遍**（PRD 的「涉及法律与地域合规的内容需专业评审」）。

## 设计稿

没有单独的画板。版式跟资源的使用指南（标题、导语、一节一个小标题，正文最宽 760px），手机上同样单栏。

「需要登录」画板底部有「用户协议、隐私政策」一行（apps.md 当时因为没有页面先不放），这次补上：登录页和登录对话框的表单下面写「继续即表示你同意《用户协议》和《隐私政策》」，两个都是链接。

## 规则

1. **两个地址**：`/[locale]/privacy`、`/[locale]/terms`。五种语言各一份，进搜索引擎和站点地图，带 canonical 和 hreflang。
2. **文字放在界面文案里**（`messages/*.json` 的 `legal`），和别的文案一样由站长改、由 `pnpm i18n:check` 查齐；繁体由 OpenCC 从简体生成。英文是准的那份：各语言之间有出入时以英文为准，每页开头写明。
3. **生效日期**写在代码里（`src/modules/legal/documents.ts`），改了条文就改日期，页面按读者的语言显示「最后更新：2026 年 10 月 23 日」。
4. **联系邮箱** `hello@ifai.io`，也写在 `documents.ts`。查询或更正资料、登录不了时删除账号、版权投诉都写到这里；能登录的读者在「账号」页自己删除账号（foundation.md「账号页与删除账号」）。站长要开好这个邮箱（或者改成别的地址）。
5. **页脚**加「隐私政策」「用户协议」两个链接，放在 RSS 前面。
6. 条文只写现在真的在做的事。以后接入 PostHog、Sentry、Langfuse，或者开放新的收集（关注、圈子），要先改这两页再上线。

## 隐私政策写了什么

按现有代码核对过：

- **账号**：邮箱、名字、头像（用 Google、GitHub 登录时由它们提供）、界面语言；登录会话记下 IP 地址和浏览器标识；登录链接的一次性记录。
- **读者自己写的**：评价（公开，署账号的名字）、收藏（只有自己看得到）、报错（联系方式选填）、提交应用和投稿 Skill（联系邮箱）。
- **日报邮件**：邮箱、语言、时区，Resend 回传的送达、退信、投诉。
- **访客计数**：IP 加浏览器标识算出的哈希，盐每天换，不存原始 IP，不同天的哈希连不起来（`src/lib/visitor.ts`）。用来算点击、安装数和限频。
- **Cookie**：只有语言（`IFAI_LOCALE`，一年）和登录会话两种，没有广告和统计 Cookie。
- **交给谁处理**：Vercel、Neon、Cloudflare R2、Resend、Inngest、OpenRouter 及其背后的模型服务商（翻译评价）、Google 和 GitHub（选它们登录时）。不卖资料，不做广告追踪。
- **留多久**：账号资料保留到账号删除；退订的订阅 30 天后删除；因为退信或投诉停发的只留邮箱和原因；限频记录 24 小时；回调记录 7 天。
- **读者能做什么**：每封邮件里退订、自己改删评价和收藏、在「账号」页自己删除账号（收藏、评价、报错、举报和投稿一起删）、写信要求查看、更正、删除资料，登录不了时写信删除账号。
- 不面向 16 岁以下。

## 用户协议写了什么

账号一人一个、自己保管登录邮箱；日报摘要、应用资料和热度是我们整理和估算的，可能有错，有更正记录；Skill 是第三方文件，静态检测不等于保证安全，安装和运行由读者自己负责，许可归作者；读者发的内容归读者，授权我们在站内展示和机器翻译，不能违法、侵权、骚扰、刷量，我们可以隐藏或删除；不能干扰网站运行、绕过限频、大量自动提交；站点设计、logo 和我们写的内容归 IFAI，RSS 可以个人使用并链回原文；版权投诉写信；免责和责任限制；读者可以在「账号」页删除账号，我们可以停用违反协议的账号；协议会更新。

适用法律和争议解决地点没写，要站长定了公司主体再补。

## 不做

- 条文的版本历史页。

## 验收标准

- [ ] `/en/privacy`、`/zh-hans/privacy`、`/zh-hant/privacy`、`/ja/privacy`、`/ko/privacy` 和对应的 `/terms` 都能打开，标题、生效日期、各节齐全，繁体页是转换出来的
- [ ] 页面源码里有 canonical 和五种语言的 hreflang；`/sitemaps/pages-1.xml` 里有这两页
- [ ] 每页页脚都有两个链接，点过去是同一种语言
- [ ] 登录页和登录对话框表单下面有同意说明，两个链接在新页面里打开不会丢掉对话框里的进度（新标签页）
- [ ] 手机宽度（375px）不横向滚动，长邮箱和长单词能换行
